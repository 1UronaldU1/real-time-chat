# Real Time Chat Application

Aplicación de chat en tiempo real desarrollada con Node.js, Express y Socket.IO, ejecutada mediante Docker.

## Requisitos

- Docker
- Docker Compose
- Git

## Clonar el repositorio

```bash
git clone https://github.com/1UronaldU1/real-time-chat.git
cd real-time-chat
```

## Ejecutar el proyecto

```bash
docker compose up --build
```

## Acceder al sistema

```
http://localhost:3000
```

## Tecnologías utilizadas

- Node.js
- Express.js
- Socket.IO
- Docker
- Docker Compose
- Git
